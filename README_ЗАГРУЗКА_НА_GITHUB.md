# СКиП 4.9.2 · Premium UI · комплект замены для GitHub Pages

**Исходный репозиторий:** https://github.com/984s2pbyn4-create/skipp-app

**Что загрузить:** четыре файла из корня этого архива:

- `index.html` — подключает оформление и UI-адаптер, сохраняя `app.js` 4.9.2;
- `sw.js` — обновляет офлайн-оболочку согласованно, без вмешательства в старый кэш медиа `v492-safety-1`;
- `premium-ui.css` — пять художественных палитр и оформление существующих классов всех вкладок;
- `premium-ui.js` — каталог тем в «Настройки → Оформление» и агрегаты «Штаба» с дельтами текущего сеанса.

**Принципиально не заменять**: `app.js`, `styles.css`, `manifest.json`, иконки, каталог `assets`, пользовательские данные и `.github/workflows`. Все перечисленные файлы/папки должны остаться в репозитории.

## Как загрузить на GitHub через iPad

1. В приложении **СКиП** создайте резервный JSON через «Настройки → Данные», сохраните его в «Файлы» и убедитесь, что файл действительно создан. Не удаляйте PWA и не очищайте Safari.
2. Скачайте ZIP этого комплекта и распакуйте его в приложении «Файлы».
3. Откройте https://github.com/984s2pbyn4-create/skipp-app и выберите `Add file` → `Upload files`.
4. Загрузите **четыре файла**: `index.html`, `sw.js`, `premium-ui.css`, `premium-ui.js` (не сам ZIP). Подтвердите замену `index.html` и `sw.js`, если GitHub об этом спросит.
5. Сделайте commit. Для более безопасного испытания желательно сначала использовать отдельную копию репозитория и отдельный GitHub Pages URL, а не рабочую версию с единственной базой задач.
6. Откройте страницу с интернетом и дождитесь обновления Service Worker. Закройте все старые окна PWA, откройте снова и убедитесь, что сохранено содержимое задач.
7. Откройте «Настройки → Оформление», выберите одну из пяти премиальных тем. Для отмены выберите «Стандартная тема» в новом блоке.
8. Проверьте PIN/заставку/звук, действия с задачами, календарь и доски, экспорт/импорт, авиарежим и открытие без сети.

## Важные технические ограничения

Это **UI-надстройка**, а не новая версия ядра. Она не меняет модель задач, PIN или хранилище. Переключение премиальных тем хранит только несекретный ID темы в localStorage (`skip_premium_visual_theme_v1`), независимо от основной настройки D.settings.theme.

Динамика счётчиков в «Штабе» рассчитана на основе агрегатов, показанных самим приложением: «В работе», «Мои задачи», «Указания», «Просрочено», «На сегодня», «Исполнители». Сравнение ведётся с первого открытия «Штаба» **в текущем запуске** и сбрасывается при блокировке. Оно не является изменением за сутки.

**Полноценный общий счётчик «Выполнено» и историческая динамика по дням пока не реализованы**: они требуют модификации внутреннего `app.js` и проверки модели статусов; показывать вымышленные цифры вместо реальных запрещено. Это функциональный остаток к следующей интеграционной версии.

CSS применяет пять тем к общим элементам вкладок: карточкам, таблицам, модальным окнам, полям, календарю, канбан-доскам и аналитике. Внешний вид зависит от собственных классов исходной версии и требует проверки на реальном iPad Safari. Художественная точность относительно первых концептов не проверена на реальном приложении.

**Старое медиа остаётся в том же кэше**, чтобы код `app.js` 4.9.2 находил заставку и звуковые файлы. Новый кэш `v492-premium-ui2` хранит согласованную HTML/JS/CSS-оболочку. SW не использует skipWaiting и не перехватывает Range для MP4.

## Что удалось проверить

- `node --check` для двух JS-файлов;
- разбор CSS `tinycss2` без синтаксических ошибок;
- соответствие двух новых ссылок `index.html` и ресурсов в `sw.js`;
- присутствие пяти идентификаторов тем и сохранение исходного имени медиа-кэша;
- моделируемый Service Worker: установка оболочки, активация, доступность видео и CSS/JS из кэша, пропуск Range-запросов MP4.

**Не выполнено:** браузерное E2E на реальном СКиП, проверка загрузки в iPadOS Safari/PWA и комплексное тестирование перехода с рабочего кэша. В доступной среде Chromium заблокировал локальную навигацию, поэтому такие проверки не заявлены как пройденные.

**Статус:** готовый комплект файлов для ручной загрузки на GitHub; осторожно испытывать на тестовой копии перед установкой на основную PWA.
