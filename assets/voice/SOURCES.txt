СКиП — голос из Logic Pro + найденные онлайн звуковые эффекты радио.

ГОЛОС: Project 2.aif (предоставлен пользователем), без изменения EQ, высоты и скорости, применено только одинаковое снижение уровня для безопасного экспорта.
ЭФФЕКТЫ: материалы Mixkit Sound Effects, адаптированные для использования в составе четырёх готовых приветствий.
— Metal button radio ping (Mixkit ID 2544), щелчок тангенты.
— Radio static FX (Mixkit ID 2561), открытие / закрытие эфирного канала.
Источник файлов: публичная копия аудиобиблиотеки https://github.com/Arnie016/flight-simulator-fable5/tree/main/assets/audio/library
Оригинальная библиотека: https://mixkit.co/free-sound-effects/static/
Условия: https://mixkit.co/license/modal/sfxFree/ . Включение звуковых эффектов в конечный продукт разрешено; отдельные исходные стоковые звуки в архив не включены.
Оригинальная звуковая библиотека использует файлы 44,1 кГц; для акцентов начальные короткие участки сигналов адаптированы к голосовой полосе радиостанции.
Файлы 01–04 готовы для выбора по времени суток в веб-приложении. WAV — монтаж; MP3 — для GitHub Pages.
