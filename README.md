# СКиП v4.7 — универсальные шаблоны досок

Готовая PWA-сборка для GitHub Pages на базе СКиП v4.6. Сохранены ранее утверждённые горизонтальная и вертикальная заставки, радиоприветствия и весь текущий формат локальной базы.

## Главное
- **Виды карточек:** простая, ФИО, собственный шаблон. Любой тип можно расширить необязательными полями.
- **Настройка в доске:** «Доски» → создать/выбрать доску → «Настроить» → вид карточки и поля. Тип поля: строка, многострочный текст, число, дата, список, да/нет. Установите требуемые поля один раз. Данные старых карточек не стираются.
- **Быстро:** «Доски» → «Быстро» — вводите название, Enter, затем следующая запись. Столбец и шаблон сохраняются.
- **Добавить списком:** вставьте фамилии или табличные данные одной строкой на карточку, дополнительные поля отделяются «;» либо табуляцией. Можно добавить тысячи записей за раз.
- **Экспорт доски в Excel:** включает все настроенные поля.
- **Темы:** исходные «Как в системе», «Светлая», «Тёмная» сохранены, добавлено пять визуальных тем: Изумрудный штаб, Графит, Голографический центр, Изумрудный HUD, Светлый командный.
- **Иконка:** из утверждённой эмблемы СКиП на заставке, одинаковая для PWA и главного экрана.
- **Текст сообщений:** для новых пользователей стандартный вариант с эмодзи. На существующих устройствах явно сохранённые пользовательские настройки не перезаписываются.
- **Обучение:** реальная интерактивная тренировка короткого и долгого нажатия «Поставить задачу» / «Напомнить»; есть отдельный этап про шаблоны досок.
- **Сроки задач:** можно вводить время исполнения и точный момент напоминания. Это видимые напоминания в открытом приложении, а НЕ системные push при закрытом PWA.

## Установка
1. **Обязательно выгрузите резервную копию** из прежнего СКиП.
2. Распакуйте ZIP и загрузите содержимое в корень GitHub Pages, включая папку `assets/`.
3. Не меняйте адрес сайта, чтобы сохранённые данные браузера остались доступны.
4. После публикации закройте PWA, откройте его повторно с интернетом, дождитесь обновления Service Worker.
5. Проверьте данные, затем «Настройки → Обучение» и «Доски → Настроить».

## Технические ограничения
- Шаблоны хранятся вместе с объектом доски (`board.template`), значения полей — с карточкой (`bcard.fields`). Старая коллекция и ключ localStorage/шифрования неизменны.
- Старая доска без шаблона открывается как «Простая» с прежними полями «Заметка» и «Примечание».
- Новые темы не меняют персональные сохранённые настройки темы.
- Рендеринг проверен в Chromium; Safari на реальном устройстве пользователя требует самостоятельной проверки.
