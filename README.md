# СКиП v4.8 · GitHub Pages

В этой версии: вход по PIN перед кинематографической заставкой; обязательная настройка PIN при первой установке; отдельная активация звука для iOS; воспроизведение заставки Full HD 1080p (исходный файл является увеличенной копией видео Kling); четыре радиоприветствия; новые темы с графическим фоном в стиле заставки; адаптивность Stage Manager; перенос на завтра; массовые действия в поиске, включая удаление в корзину; редактирование повторений в Планировании; новые иконки по утверждённой эмблеме.

## Установка

Загрузить **все** файлы и папку `assets` в корень репозитория GitHub Pages, не удаляя `.github/workflows`. После публикации обновить страницу, при необходимости переоткрыть установленное PWA.

**Важно:** Перед обновлением сохраните резервную копию из приложения. Не удаляйте само веб-приложение с домашнего экрана до создания проверенной резервной копии: его локальная база может храниться в браузерном хранилище.

## Вход и звук на iOS

На первом запуске приложение требует создать PIN (6 цифр) и подтвердить его; после этого запрашивает ввод PIN снова и только затем показывает заставку. Если PIN уже есть, он не сбрасывается. На экране ввода доступна кнопка «Активировать звук заставки» с пояснением ограничений iOS. Разрешение звука зависит от Safari, а не от приложения. Если Safari отклоняет звук, ролик запускается беззвучно и предлагает нажать подсвеченную кнопку непосредственно на заставке. Никаких гарантий фонового autoplay со звуком нет.

## Уведомления

Напоминания внутри открытого приложения. Отправка системных push-уведомлений при закрытом PWA через статический GitHub Pages не реализована.

## Условия использования и приватность

Все пользовательские задачи сохраняются в локальной базе. Шифрование включается после установки PIN; существующие зашифрованные базы не расшифровываются или не перезаписываются до верного ввода PIN.
