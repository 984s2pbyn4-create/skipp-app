# СКиП v4.9 — исправление запуска заставки и тем

- PIN вводится перед каждой заставкой; кнопки включения звука убраны. Последнее нажатие PIN инициирует Web Audio до проверки кода, воспроизведение начинается **только после** успешной проверки.
- Короткие ролики теперь содержат только видео (без аудиодорожки). Звуковые эффекты и радио-приветствие воспроизводятся отдельными дорожками при успешной активации AudioContext. Это помогает избежать блокировки autoplay на iOS.
- Safari всё ещё вправе запретить автоматический звук в отдельных режимах. Если звуковой движок заблокирован, заставка продолжится без принудительных кнопок и не должна зависать.
- SW не перехватывает MP4 и не подменяет HTTP Range-ответы. В офлайне возможен резервный неподвижный экран HUD, если видео не было сохранено браузером ранее; оболочка и голосовые ресурсы кэшируются.
- Новые темы: «Командный HUD», «Тёмный штаб», «Тактическая сетка», «Дневной изумруд». Старые базовые «Как в системе», «Светлое», «Тёмное» остаются. Удалённые промежуточные темы при выборе прежних настроек преобразуются в ближайшие новые.
- Большая эмблема без повторного названия в боковой панели, компактная эмблема на узких экранах.

## Обновление
Заранее экспортируйте резервную копию задач. Загрузите содержимое архива в корень репозитория GitHub Pages; оставьте свою `.github/workflows`. Замените `app.js`, `styles.css`, `sw.js`, `index.html`, мультимедиа и другие файлы сборки. После публикации закройте PWA, затем откройте повторно для активации нового кэша.

**Техническое ограничение:** В iOS невозможно программно выдать разрешение на звук одним только фактом корректного пароля. Приложение использует непосредственный тап по последней цифре PIN для активации Web Audio, но результат зависит от политики Safari и настроек устройства.

## Проверено в сборке

- JS приложения и Service Worker проходят синтаксическую проверку.
- Интерфейсным тестом подтверждены установка PIN, повторный вход, появление заставки, отсутствие кнопок управления звуком и работа экрана «Штаб».
- Все MP4 имеют видео H.264 без аудиодорожки, эффекты извлечены отдельно; четыре голосовых MP3 сохранены.
- Архив GitHub Pages содержит все необходимые исходники и ресурсы.

Полное воспроизведение в Safari на вашем iPad остаётся обязательной проверкой после публикации: этот браузер здесь недоступен.
